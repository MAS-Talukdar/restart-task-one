#### 1) What is the difference between `null` and `undefined`?

Answer:
Undefined means missing value by JS. On the other hand null means intentional absence of a value by developer.

#### 2) What is the use of the `map()` function in JavaScript? How is it different from `forEach()`?

Answer: `map()` returns a new array on the other hand `forEach()` returns undefined.

#### 3) What is the difference between `==` and `===`?

Answer:
`==` a week equality and `===` means strong equality.

#### 4) What is the significance of `async`/`await` in fetching API data?

Answer:
When fetch data from an API, it takes time. JavaScript does not wait — it continues running code. `async`/`await` lets pause execution until the data comes, without blocking the full program.

#### 5) Explain the concept of Scope in JavaScript (Global, Function, Block).

Answer:
Scope মানে হলো — একটি variable কোথায় declare করা হয়েছে এবং কোথা থেকে সেটি access করা যাবে।
Global Scope: যে variable function এর বাইরে declare করা হয় |
Function Scope: যে variable function এর ভিতরে declare করা হয় |
Block Scope: যে variable { } block এর ভিতরে let বা const দিয়ে declare করা হয় |
